8. CRIAR O PRIMEIRO ADMINISTRADOR
============================================================

[ ] Não colocar a chave dentro do repositório.
[ ] Definir GOOGLE_APPLICATION_CREDENTIALS.

PowerShell:

  $env:GOOGLE_APPLICATION_CREDENTIALS="C:\caminho\service-account.json"
  npm run admin:set -- seu-email@exemplo.com

[ ] Sair e entrar novamente no aplicativo Web.
[ ] Abrir /controle-assinaturas.
[ ] Testar:
    - listagem;
    - busca;
    - paginação;
    - concessão por UID;
    - concessão por e-mail;
    - prazo;
    - fundador;
    - remoção;
    - histórico.
[ ] Confirmar que uma conta sem claim admin recebe 403.

Para remover um administrador:
